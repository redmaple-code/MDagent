# 文献复现交付标准(Mode B)

> 2026-09-05 用户拍板(含多模型拆分条款)。适用对象:Mode B(read_paper → 建模 → 动力学 → 分析)跑文献复现的每一次交付。
> 总原则:**合规判据不是"文件存在/跑完了",而是"论文信息逐条对得上 + 关键数值对得上"**。
> 对不上的产出不是废品——它是带标准答案的失效样本,结账进演化层燃料(根因分类+后验记账)。

---

## 0. 多过程拆分:一篇文献 → 多个模型

论文的模拟通常**不是一跑到底**:交联/退火/拉伸/热解/烧结……是多个独立模拟过程,
每个过程**需要自己的模型**(各自的 data 输入 + in 脚本,前一个过程的产物是后一个的输入)。
交付的第一步是**拆分表**(放 `复现对照表.md` 开头),不许把多过程糊进一个 in 脚本里混跑:

| 阶段 | 过程目的 | 输入模型 | 输出产物 | 对应论文步骤 |
|---|---|---|---|---|
| M1 | 交联网络构建+平衡 | `crosslink.in` + 单体 data | `stage1_end.data` | §2.3 交联协议 |
| M2 | 升温热解 | `pyrolysis.in` + `stage1_end.data` | `traj_pyro.lammpstrj` | §2.4 升温程序 |
| M3 | 淬冷+单轴拉伸 | `tensile.in` + `pyro_final.data` | 应力应变曲线 | §3.2 力学测试 |

拆分红线:
- **一过程一模型**:每阶段独立 in 脚本,产物显式落盘(`write_data`/`write_restart`),
  下一阶段 `read_data`/`read_restart` 显式衔接——衔接文件名必须出现在拆分表里;
- 阶段间**不许隐式传状态**(重启文件之外的手工改 data 必须写明改了什么、为什么);
- 每个阶段**独立满足** §1 对照、§2 汇总、§3 指标三条标准(下文所有"模型"字样
  均指"该阶段的模型");任一阶段卡死=该阶段先转失效样本,不许跳过阶段硬交付。

## 1. 建模阶段交付标准:论文模拟信息全对照

论文里**所有**与模拟相关的信息,必须逐条对照,并指明**该信息在模型中体现在什么地方**。
缺一条、或"体现了但指不出位置",建模阶段不许交付。
**多过程复现:对照表按阶段分节,每条"模型体现位置"必须带阶段号**
(如 `M2: pyrolysis.in 第 14 行 fix nvt`),不许只写"在输入脚本里"。

对照表(每篇复现必填,每个阶段一节,放进 case 目录 `复现对照表.md`):

### M1 交联网络构建

|---|---|---|---|---|---|
| 化学组成/配比 | §2.1 | EPON862:DDS=2:1 | M1: data 文件分子清单 + `build.log` | 2:1 | ✓ |

## 2. 模拟体系汇总描述

每次交付开头必须有一段**体系汇总**(独立于对照表,给人快速读懂"你模拟的是什么")。
**多过程复现:先一段总体描述,再按阶段各一小段**,并显式写出阶段衔接:

```
体系:EPON862/DDS 环氧树脂交联网络热解(复现自 <文献>)
组成:EPON862 单体 ×80 + DDS ×40,交联度 85%,共 12 480 原子
力场:ReaxFF(ffield.reax.cand,C/H/O/N),QEq 电荷平衡 tol=1e-6
盒子:45.0×45.0×45.0 Å,周期边界三向,初始密度 1.14 g/cm³
过程拆分:M1 交联+平衡 → M2 升温热解 → M3 淬冷拉伸

M1 交联网络构建(crosslink.in):
  NVT(Langevin)300K 平衡 50 ps → 交联反应 200 ps;timestep 0.1 fs;
  产物 stage1_end.data(交联度 85%,对照论文 §2.3)
M2 升温热解(pyrolysis.in):
  输入 stage1_end.data;NVT 600→3000K @ 50 K/ps,生产 200 ps;timestep 0.1 fs;
  输出 traj_pyro.lammpstrj + pyro_final.data;产物统计每 1 ps
M3 淬冷拉伸(tensile.in):
  输入 pyro_final.data;300K 淬冷 20 ps → NPT 单轴拉伸 1e8/s;
  输出应力应变曲线(对照论文 §3.2)

输出:traj 每 5 ps 一帧(dump D1),热力学量每 100 步(thermo),QEq |q|max 监控
算力:8 核 MPI,M1 ~2 h / M2 ~6 h / M3 ~3 h,全程预计 ~11 h
```

## 3. 跑完交付标准:关键指标与文献对比

跑完不是终点。**论文报道的主要数值指标**,必须逐个算出模拟值并对比(放 `指标对比.md`);
**多过程复现:指标表注明每个指标出自哪个阶段的产物**(M1 密度、M2 char yield、M3 模量):

| 指标 | 出自阶段 | 文献值 | 模拟值 | 偏差 | 判定 |
|---|---|---|---|---|---|
| 交联度 (%) | M1 | 85 ± 3 | 84.7 | -0.3pt | ✓ 吻合 |
| 密度 (300K, g/cm³) | M1 | 1.15 ± 0.02 | 1.14 | -0.9% | ✓ 吻合 |
| char yield @3000K (wt%) | M2 | 22.5 | — | — | 待算 |
| 弹性模量 (GPa) | M3 | 3.2 ± 0.3 | — | — | 待算 |

判定规则:
- **全部主要指标在文献误差带内** → 复现成立,交付;
- **任一主要指标显著偏离** → 不许润色交付:标明偏差,该算例(及卡住它的阶段)转
  **带参照失效样本**——结账进 kit 策略库(根因分类)与演化层观测流,偏差值与文献值一并入账;
- 论文报了但模拟没算的指标 → 标"待算"不许删行,分析补齐后才许关闭该 case;
- 某阶段产物是后阶段输入的(M2→M3),其指标偏差会向下游传导:**上游阶段指标未判 ✓,
  下游阶段不许开跑**——否则偏差来源无法归因;
- **欠约束项强制风险评级**(2026-09-09):论文未报、由 agent 自行取值的参数,凡取值不同
  可能翻转结论的,对照表该条必须加标"结论翻转风险:高/低";高风险项须**预登记一个
  裁决实验**(只改该参数的对照 run,写进拆分表),不许只取"工程上干净"的默认值静默交付——
  默认值必须能被追问出"为什么是这个值";
- **差异型结论强制噪声地板标注**(2026-09-09):凡"A 比 B 好/差 X%"型结论,必须先估计
  模拟噪声地板(同体系独立重复 run 的指标涨落),并按三档标注:差异 > 3×地板 = 显著;
  1–3× = 提示性; < 1× = 不显著。**噪声地板都估计不出来的分析脚本不许下差异结论**,
  噪声内的差异写成"一致"或"显著"都算判定违规。

指标选取:以论文**摘要/结论里引用的数值**为主要指标(通常 2~5 个);
其余论文报了数值的量为次要指标,能算则算,不算须注明原因。

## 与既有链路的关系

- **Mode B 产出物升级**:蜂群拆解(结构建模面/力场面/动力学面/分析面)的输出,
  交付前按 §1 对照表自检;§2 体系汇总就是建模思路文档的开头段;
  §0 拆分表就是动力学骨架的骨架——阶段数 = 模型数,不允许"一锅炖"。
- **演化层燃料**:§3 判"失效"的样本,失效签名进五个根因桶(thermal_runaway/
  QEq_instability/atomic_ejection/structural_collapse/input_error)之一或标注
  "物理偏差"(非崩溃类),同签名 14 天 ≥4 次触发 L2 起草;pipeline CRITICAL 事件
  经 `events/pipeline.jsonl` 进 observe 复发统计;交互层软失败(用户打断/工具错误/
  审批否决)经 `events/friction.jsonl` 进同一观测流(2026-09-09 经验沉淀)。
- **准则 8 落地**:合规判据 = §0 拆分表阶段齐全 + §1 各阶段表无空格 + §3 表全部指标有判定。
