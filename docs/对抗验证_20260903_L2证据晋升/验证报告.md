## 三、新定稿决策(并入基线)

- **L2-1 证据门类触发、无豁免**: `cls in evidence_classes` 即过证据门,与 tier 无关;approver 仅作审计记录,不豁免任何证据检查。
- **L2-2 门重执行纪律**: install 必过沙盒试跑且由门子进程重跑(考题出自模板代码);提案自附 sandbox_report.json 只作审计佐证,绝不作门输入(杀自证)。
- **L2-3 血统校验**: install/promote/demote 三操作均要求条目 `_LINEAGE_KEYS` 与模板 instantiate 产物一致(success_rate/uses 合法漂移除外);off-template 一律拒。
- **L2-4 内容禁闭**: auto 类 `_check_auto_db_confinement`(strategies/history 逐字节不动);evidence install 同纪律(单写者)。
- **L2-5 TOCTOU 双闸**: 门前内存模拟断言 + 落盘后按(备份, 盘上)重放断言,不过→ROLLED_BACK 非 REJECTED;promote 统计按当前盘新读 db 重算,不信 meta/evidence 携带数。
- **L2-6 demote 优先**: 横扫与门两侧对称——连败尾≥demote_fail_streak 的 canary 只可走 demote;3W→3F 反转序列永不起草 promote。
- **L2-7 僵尸锚点**: 零结账 canary 饿死计时锚=history 首账 ts 或 LEDGER 最早 install 记录 ts;LEDGER 行带 op/specialist_id;超 canary_max_age_days(30d) 饿死降级。
- **L2-8 墓碑 fail-closed**: 墓碑 ts 解析失败/未来 ts 一律按冷却内处理;demote 配套 auto 类墓碑提案(penalty 封顶+tombstone),冷却 7d 防立即重起草。
- **L2-9 no-op 判失败**: apply 零改动=策略失败记账(防 Beta 投毒),备份延迟到有真实改动才建。
- **L2-10 DSL 规则安全**: 白名单键/flags⊆{I,M,S,X}/count∈[1,20]/长度上限/嵌套量词+交替量词+dotstar≤2 启发式/`\N`+`\g<>` 反引用全审计/version bool 拒/apply 异常包装 ValueError;规则只出自人工模板骨架(forbidden_paths 护执行器/模板/沙盒)。
- **L2-11 canary 语义**: truthy 即 canary(畸形真值 fail-closed);两轮选择(非 canary 优先,尽没才看 canary);研究推荐 canary 一律压制回退打分。
- **L2-12 R6 时限**: rollback 对含 `.v3.3_strategy_db.json` 且条目 ts>24h 拒整文件还原,引导正向修正提案;≤24h 维持现状。
