# MDagent DSH Button Visualization — Design

Date: 2026-10-13

Status: **LOCAL_IMPLEMENTATION_VERIFIED / FINAL_REVIEW_FIXES_VERIFIED / NOT_DEPLOYED**.

Revision 2: 按用户最新要求，改为按钮操作；此前自然语言控制设计已被本版本替代。沿用原文件路径，便于继续审阅。

## 1. Goal and scope

在现有原生 DSH 聊天页面中提供简单的结构/轨迹查看面板。用户点击“3D 预览”，选择已登记结构或已完成任务结果，通过按钮和时间条查看。预览坐标只经计算端 → 本地连接器 → 浏览器传输；服务器继续提供元数据与授权。

首版范围：本 Agent 已登记的输入结构，以及当前有效、已接受的已完成任务结果。配套拓扑与轨迹由已有产物 manifest 自动匹配，用户无需手工配对。

本版不增加可视化语言工具、不通过对话自动打开或控制面板，测试入口不启用既有 Agent 显示联动。普通 DSH 聊天与原科研工作流保持独立；按钮查看不依赖模型调用。外部超算目录导入、模型截图理解及新的科研分析不纳入本版。

## 2. Existing foundation

当前 `BioAction` 已在原生聊天页头提供“3D 预览”；dock 已有选择、播放/暂停、时间条、表示切换和居中。主要工作是整理选择入口、收紧为唯一直连，并将当前构建接到本地原生 DSH 界面验收。

继续复用 Molstar、只读 helper、单次范围许可、SourceRef/manifest/文件 SHA、真实源帧/时间与用户镜头。已有 DSH、TypeBox、Schemastery、Molstar、Vite 和 modeling Python 兼容，无需新增依赖。

当前 cloud 仍保留预览中转读取，直连资格也依赖整组包含 read 的 action。仅隐藏模式下拉框不能满足唯一直连要求。已有 Agent 显示接口中读取一个字节的来源核验需一并改为元数据核验，避免保留隐藏的中转路径。

## 3. Minimal UI and selection

操作顺序：**点击“3D 预览” → 配对本地连接器 → 选择对象 → 点击“打开” → 播放或定位**。

| 控件 | 行为 |
| --- | --- |
| 选择查看对象 | 分组列出“输入结构”和“已完成任务结果”，显示文件名或任务名及版本；有多个已完成阶段时选择明确阶段。 |
| 打开 | 核验当前来源并加载结构/轨迹，显示加载、排队或错误状态。 |
| 播放 / 暂停 | 播放当前轨迹；静态结构禁用播放。 |
| 时间条 | 定位真实采样帧，显示源帧号和实际时间及单位。 |
| 表示 / 居中 | 保留简单表示切换和居中；鼠标拖动旋转、滚轮缩放。 |
| 收起 | 关闭当前面板并释放该面板的读取资源。 |

选择后显示配套结构/轨迹文件名、任务版本/阶段和可用时间范围。暂未核验的元数据说明“打开时核验”；不能通过文件名猜配对或凭文件存在推断任务已接受。初次展示明确的“请选择”项，避免误打开第一条结果。空清单提示通过“Bio 任务”上传结构或等待任务完成。

最终实现中，下拉框表示待打开对象，“当前显示”标签在成功打开后更新，待选或打开失败时保留实际来源。输入预览 ID 绑定原登记 ID、精确文件名和 SHA-256，科研输入 ID 保持原样；旧 ID 与哈希仅在唯一匹配时恢复。

优先复用现有 human inputs/list/get/artifacts API 做有界分页和 SourceRef 解析，不新增面向模型的共享目录工具。每次打开重新核验 revision、manifest 与权限；过期来源、未接受结果和跨会话请求拒绝。多段轨迹遵循 manifest 的顺序与真实时间。

默认只展示基本控件；已有原子集合和详细窗口等功能集中到折叠的“更多设置”，不新增高级功能。正常桌面、390px 窄屏及短窗口下，按钮必须可见或可滚动，不能被面板裁切。切换会话、关闭和迟到的加载结果继续使用现有生命周期隔离。

## 4. Direct preview only

移除 auto/relay 选择，所有预览文件固定使用 direct-only。未配对、断线、恢复、预取和错误处理均不回退到中转。连接区保留配对入口、状态和断开；配对码清空且不进入对话、URL 或日志。

服务器拆分预览控制资格与坐标读取资格；直连只要求 describe/prepare/status/window/cancel 与 direct-open/permit/close，不再要求中转 read。该版本预览中转入口在进入 Bridge 坐标读取前明确拒绝，即使旧 binding 含 read 也不能走中转。

来源核验使用权威元数据/已发布 manifest，不经 Bridge 读取坐标字节。文件哈希、host/UID/target/pairing/epoch 校验、有界传输和浏览器缓存的重新授权保留。连接问题在面板显示明确重试提示，身份、来源和权限错误继续拒绝。

本节仅约束网页预览；原科学产物下载、输入上传和计算审批/提交不改动。

## 5. Native local DSH experience

用当前源码的原生 DSH 网页和 Bio 会话验收，不另造聊天界面。沿用既有模型配置供普通聊天使用，可视化按钮不发起模型请求、不启用 Agent 显示工具或等待模型响应。

测试会话、状态和工程数据放在本轮独占目录，复用依赖，不复制整仓或科学环境，不修改原 DSH_HOME、生产凭据或配置。已有模型凭据如普通聊天需要，仅通过安全引用传入子进程内存环境，不复制到测试目录或日志。

当前无真实超算连接配置，原生 DSH 体验可先使用明确标注的本地 stdio 工程计算端和工程样例，验证按钮、来源、真实帧及直连许可链。它不证明真实 SSH、HTTPS 或实际提速；这些保持待配置验收。测试不取得生产计算权限，不运行正式 MD。

## 6. Validation and handoff

1. 在原生 DSH 中点击打开、选择输入结构/完成任务/明确阶段；验证空清单、分页、重名、过期来源、未接受结果及会话隔离。
2. 实际浏览器验证结构旋转/缩放/居中、轨迹播放/暂停、时间条定位、源帧与实际时间、切换来源和镜头保留；静态结构不播放。
3. 核对按钮不调用模型、Agent 显示联动未启用；不把未启用联动显示为用户错误。
4. 请求与计数确认预览中转坐标为零；未配对/断线不回退，直接请求旧中转入口亦拒绝；来源核验不读取坐标。
5. 桌面、窄屏和短窗口控件不被裁切；切会话/关闭停止自身传输。运行相关权限、来源、connector、player、UI 与科学任务面板回归。
6. 更新实际前端和候选包，用当前构建验收；保留源码、未提交成果、回退包和必要证据，不提交/推送/部署。
7. 临时路径逐项登记；停止不用的服务后仅清理任务独占、可重建且非交付/证据的产物，记录清理前后空间。

本修订已于 2026-10-13 获用户确认，继续编写精简实施计划，沿用本会话 Native 方式。产品已本地实现并工程验证；真实超算 SSH/HTTPS/提速继续待连接配置。
