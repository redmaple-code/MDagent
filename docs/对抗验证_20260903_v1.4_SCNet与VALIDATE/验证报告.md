## 二、首轮发现与处置(全修,均带回归测试)

**SCNet 面**(attack F1-F10 + audit 交叉):
- 高:F1 伪造批准文件被接受(人工闸可被同 uid 自批绕过)→ PIN 制人工闸(C1)+ 批准文件强 schema。
- 中:F2 一次性批准并发双花 → `_take_approval` 原子 rename;F3 plan_hash 只绑 basename → 文件内容 sha256 入哈希;F4 cluster_id/work_root 不进哈希 → 全绑定(C2);F5 case_id `../` 逃逸 → ASCII 白名单(C5);F6 配置类型混淆 fail-open → 类型严格 fail-closed(C6)。
- 低:F7 无下界(nodes/ppn/walltime)、F8 崩溃式拒绝零审计、F9 闸在网络之后(2 次外发)、F10 审计写崩误判 → 全修。

**VALIDATE 面**(audit_validate):
- 高 H1:`-nan` 不在词表穿透验收(glibc 实锤)→ 词表扩编 + 逐值 `math.isfinite` 双保险(V1)。
- 中 M1:畸形 validate_timeout 令任务永久卡 VALIDATE → 兜底 300 + 钳位 [30,3600](V3);M2:`float("1e999")` 静默溢出 inf → 同 H1 修复覆盖。
- 低 L1:验收失败 bus 永留 VALIDATING → 落 FAILED + 飞书。
