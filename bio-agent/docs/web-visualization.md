# 网页结构与轨迹预览

打开一个已有 Bio 任务会话后，页头会显示 **结构与轨迹** 和 **Bio 任务** 按钮；首页与空白新会话保持原生 DSH 布局。点击 **结构与轨迹**，配对本地连接器，选择已登记结构或任务中已完成阶段的接受结果，再点击 **打开**。建模完成的结构、计算后的结构和轨迹都通过对应阶段的结果清单查看，无需等待整个工作流结束。多个完成阶段需明确选择；任务和配套文件由接受 manifest 核验，不按文件名猜配对。右侧视图可收起；聊天输入和原来的 **Bio 任务** 入口继续可用。部署尚未启用时，页面会说明该状态。

预览面板、Bio 任务窗口、按钮、文字和 3D 背景跟随 DSH 的 **浅色 / 深色 / 跟随系统** 外观设置。切换主题立即更新当前面板，保留结构、帧和镜头，无需重新配对或打开。预览标题、对象选择和播放按钮固定显示，只有内容与更多设置滚动；窄窗口中也可直接收起或暂停。

拖动标题栏可移动窗口；拖动右下角可分别调整宽度和高度，比例不限。**复位** 或双击标题栏恢复初始位置与大小；聚焦标题栏或右下角后也可用方向键微调。窗口会保持在页面可见范围内，3D 画面随窗口调整，保留结构、帧和镜头方向。

在播放按钮上方选择 **风格模板**，一次切换表示方式、配色和质感。**生物与分子** 提供经典蛋白、蛋白彩虹、球棍模型、水分子、空间填充、论文简洁、金属雕塑；**材料 · LAMMPS** 提供元素原子、金属晶体、界面分组、材料球棍、轻量线框。模板使用已经加载的原子，不生成或替换模型，也不更改坐标、时间、镜头与 DSH 日夜主题。改变表示方式时，新旧表示在同一个可回滚事务中替换；失败保留先前画面。保存后的模板从实际表示属性恢复；手动微调后与预设不一致时显示 **自定义**。

查看纯水时，在 **更多设置 → 预览原子集合** 选择 **全部原子** 后点击 **打开**，再选择 **水分子** 模板。氢和氧按元素着色，使用哑光球棍；水的球棍采用较清晰的原子球和细键比例。蛋白骨架模式下附带的水也使用这一比例，蛋白和配体保持原有比例。材料模板使用的大原子球、链色或统一色容易遮住水分子的形状；切换模板即可恢复，不需要重新计算。只有周期盒的概览不包含水原子，仍需先加载全部原子。

点击 **Unwrap** 可恢复被周期盒边界拆开的分子，并连续展开轨迹；点击 **原始** 切回原始坐标。切换保留当前时间、配色、已选原子和视角，播放会暂停。处理失败时保留先前画面。只有周期盒的概览需先加载原子。Unwrap 的坐标可能超出原始周期盒，这是连续展开的结果，不会自动居中、平滑或重新包回盒内。

计算端先根据登记 PDB 的显式连接和 OpenMM 标准拓扑恢复分子连接，再用已有 MDAnalysis 按连接片段恢复完整分子，最后调用原生 PyMOL `cmd.pbc_unwrap(..., bymol=1)`。处理从源帧零开始，逐帧保留每帧的周期盒，在选取显示原子和抽帧之前完成；详细窗口沿用相同的前缀。输出是独立的预览缓存，记录模式、软件版本和运行时指纹，原始结构、轨迹及已验收结果不变。缺少有效周期盒、可靠分子连接或源轨迹存在明确时间缺口时会报错；不会按距离猜测配体键，也不能恢复原始存储采样中已经丢失的运动信息。

非标准残基中的多原子分子必须有连通的已知键图；仅提供几组互不相连的 CONECT 记录不足以确认完整分子。Unwrap 作业使用独立的窗口操作标识，切换来源、断开连接或收起窗口时取消本窗口作业；取消先于生成请求到达也会被保留。其他窗口正在处理的作业不受影响，完成的预览缓存可复用。

需要在**计算端**配置可用的 PyMOL/PyMOL2。默认复用计算 Python；若已有独立 PyMOL 环境，可在启动计算端 Bridge 前设置 `BIO_PREVIEW_PYMOL_PYTHON=/absolute/pymol-environment/bin/python`。本地工程配置会传递这个操作员设置；SSH 使用的是远端进程自己的环境，本地路径不会自动成为远端配置。该路径不由浏览器提交，不包含在公开预览元数据里。没有 PyMOL 时原始预览仍可用，Unwrap 会提示配置缺失；不会自动安装或改动科学环境。浏览器内的渲染仍由 Mol* 完成，轨迹数据继续经超算直连。使用前应以真实轨迹单独验证，显示展开不替代正式扩散分析。

播放按钮下方可选择 **自动配色 / 元素色 / 链色 / 残基色 / 序列彩虹 / 统一色**。元素色采用碳灰、氮蓝、氧红等元素颜色；自动配色沿用骨架按链、其他组分按元素的显示方式。统一色显示颜色选择器，可自选颜色。**哑光 / 亮面 / 金属感** 调整显示质感；线条仅使用配色，质感选项禁用。残基色用于区分蛋白残基，序列彩虹按聚合物残基序号渐变，不能用作材料的原子类型色。

材料模板是当前查看器的显示预设，不增加 LAMMPS dump/data 文件读取或 atom type 到元素的映射；元素色依赖已登记拓扑的元素信息，界面分组按结构已有链标识上色，没有分组标识时无法区分界面组分。球棍、线框沿用查看器识别的连线，不代表 LAMMPS 力场中的 bond 或邻居列表。论文简洁模板是显示配色，尚不包含图片导出或出版验收。

配色和质感只更新当前浏览器的表示属性，保持来源、轨迹时间、选择和镜头，不重新生成或下载轨迹。快速拖动颜色选择器会合并待处理变化。保存视图的 v2 元数据包含配色、颜色和质感；旧 v1 视图仍可恢复，使用自动配色与哑光。源码包中的前端与 Node runtime 必须配套更新。

首次查看请先点击 **连接本地** 完成配对，再点击 **打开**。连接状态显示在连接按钮旁，加载和错误提示按需出现；正常查看时不显示额外说明。配对成功后收起端口和配对码输入，保留连接状态与 **断开** 按钮。重新打开面板后需要重新配对。

下拉框表示待打开的对象，**更多设置** 中的 **当前** 信息记录画面中的实际文件、阶段与时间范围。选择其他对象或打开失败时，该信息保留当前来源；成功打开后才更新。上传结构或任务完成后，点击 **刷新清单** 获取最新对象与有效阶段，当前画面、镜头和播放位置保持不变。已失效的选项不能再次打开；选择新版本后重新核验来源。输入预览身份同时绑定登记 ID、精确文件名和 SHA-256，同 ID 的不同文件可以分别查看；科研输入 ID 保持原样。旧视图中的输入 ID 仅在 ID 与哈希唯一匹配时恢复，否则重新选择。

对象选择下方的 **计算进度** 可展开或折叠；摘要固定显示，详情位于可滚动的内容区，矮窗口可滚动查看或调整窗口大小。打开任务的已接受结果时，自动关联该工作流的精确版本；打开输入结构时，展开进度区，在 **关联任务** 中显式选择本会话的计算任务。清单包含还没有可查看结果的运行中任务，**刷新 / 更多** 可更新或翻页。关联进度不会替换当前结构、移动镜头或影响轨迹播放；切换到另一来源会清除原输入结构的手动关联。该关联仅在本次窗口中有效。

进度显示当前计算阶段及已完成阶段数，并注明当前查看的结果阶段。平衡 / 生产模拟按工作进程实际发布的本阶段步数计算百分比，阶段用时也来自该工作进程。取得至少三个稳定的步数增长速度后才显示预计剩余时间；不稳定、重试或断线时撤回估算。建模、最小化、排队及没有可信步数的阶段不显示虚构百分比。步数到 100% 而任务尚未验收时显示 **结果整理与校验**；只有工作流及所有阶段均已完成才显示 **已完成**，其满格条表示接受后的工作流完成度，不补造缺失的步数记录。失败、取消与状态未知保留实际记录并标明状态。

进度每次请求完成后约 5 秒刷新，只读取现有任务状态，不提交新计算或推进下一阶段，不创建完整工具记录。接口复用本会话已有的 `human:get` 读取权限，返回受控的阶段与步数元数据，不包含坐标、采样数组、日志、nonce 或路径；轨迹仍经超算直连。进度断线保留上次记录并重试；版本变化或权限失效停止轮询，需重新关联。关闭窗口或切换会话会取消客户端在途读取与后续刷新；已送达计算端的只读查询可能完成，迟到回复被丢弃，不中止科学计算。已完成、失败和取消后停止自动轮询，可手动刷新。当前接入 Bio/OpenMM 任务；LAMMPS 显示模板不会自动获得其计算进度，也不使用旧监控器的全局百分比。

默认概览显示蛋白 Cα 骨架及模型报告中已识别的配体重原子，最多包含 200 个真实源帧，并保留首末帧。独立小分子可选择溶质重原子。纯水默认显示源周期盒；未识别的配体或缺少 Cα 时会说明原因，可显式选择溶质重原子或全部原子。不会猜配体或随机丢原子。

时间滑条定位到最近的真实采样时间，等距时选择较早的帧。页面显示原始帧号和 ps 时间；时间间断保留。拖动时间或暂停后点击 **播放**，从当前显示帧继续，播放到末帧后循环。播放速度为每秒 1–20 个预览帧，默认 10。没有下一帧时暂停在当前帧并显示缓冲。播放速度和屏幕刷新率不会改变模拟采样时间，也不会生成插值帧。

**查看详细窗口** 使用从 1 开始的原始帧号，首版每次最多 64 帧，保留窗口中的每个真实帧。**返回概览** 恢复抽样预览。原子集合、播放速度和详细窗口位于折叠的 **更多设置**。旋转、缩放和拖动时间可以结合使用；切换轨迹帧保持当前镜头。收起或切换会话会释放当前面板的读取资源；重新打开后重新选择对象与核验来源。静态结构仅显示单帧，播放禁用。

本版使用手动按钮，不注册或调用模型显示工具。打开、播放和定位均不需要模型回复。科学任务审批、提交和原始产物下载沿用原“Bio 任务”。

## 数据与低带宽边界

派生在登记的最终计算节点完成。原始 DCD、输入、分析、日志、checkpoint 和接受记录保持原样。XTC 预览采用 `precision=3`（0.001 nm），坐标往返误差目标不超过 0.01 Å；预览不用于替代高精度分析或判断收敛。拓扑、原子映射、分段文件及真实时间映射均绑定来源与 SHA-256。

服务器仅发送控制元数据和前端资源，所有租户共同使用最多 **4 Mbps** 的发送预算。预览文件固定经 **超算 → 本地连接器 → 浏览器**，不经服务器中转；未配对、断线或资格失效会停止。每视图最多两个在途请求；HTTP 请求目标 256 KiB、硬上限 1 MiB。每段最多 64 帧、解码坐标最多 32 MiB；当前与预取坐标预算最多 64 MiB。首次加载 JS/CSS 比再次打开耗时，浏览器缓存可减少后续传输。大体系的全部原子冷加载时间仍受数据体积限制。

每计算项目的派生存储上限为 256 MiB，每租户最多一个预览 helper，使用同一科学资源池中的 1 CPU 和一个任务槽，不领取 GPU。墙钟上限为 120 秒；内存与 CPU 预留不等于 OS 强制限制。取消或状态未知时保留证据与必要租约。没有自动清理或原始数据删除。

取消或失败后，确认原 helper 已退出即可重新点击 **打开**。新的执行 attempt 保留旧任务记录与失败目录，并将残留计入配额；只有完整预览会发布到文件出口。状态 `UNKNOWN` 时先核对原 helper，继续关联原任务，避免重复启动。

## 构建与部署

独立目录 `web/visualization/` 精确锁定 Molstar 5.13.1 / Vite 8.2.2。复用已有兼容 Node/pnpm；安装不修改根 workspace lock 或科学环境：

```sh
cd bio-agent/web/visualization
pnpm install --ignore-workspace --ignore-scripts --config.auto-install-peers=false --frozen-lockfile
cd ../../..
node scripts/build-bio-visualization.mjs
node scripts/build-bio-ui.mjs
```

管理员需在操作者拥有的 binding 中明确授权 `preview:describe/prepare/status/window/cancel` 与 `preview:direct-open/direct-permit/direct-close`。不需要 `preview:read`，该旧入口会拒绝所有预览坐标读取。旧 binding 没有这些 action 时，科学工具仍按原权限工作。候选源码不会自动修改真实 binding。

API 服务使用单进程共享发送裁决器；部署多 worker 时没有共享后端则拒绝启用。进程锁及 PID 检查也会拒绝第二个独立裁决器。公网应将 `/v1/bio/preview/*`、`/v1/bio/visualization/*` 交给同一个 API 服务；tenant 的 `/_bio/preview/*` 保持 loopback 私有。JSON RPC、浏览器 cookie 和每实例 world token 沿用现有鉴权。URL 不含 token，模型不能获取私有 transport。

构建清单仅发布当前带哈希的 JS/CSS、压缩版本与 notices；不发布 source map、node_modules、科学环境或用户结果。KSH 小文件提取与补丁记录在 `provenance/visualization-source-snapshot.json`，科学 runtime 未修改。

## 本地验收

```sh
node scripts/validate-bio-visualization.mjs --out /absolute/new/evidence-directory --shared-mbps 5 --rtt-ms 100 --viewers 1,3,5 --duration-seconds 180
```

入口启动一个 loopback 网关，打开输出 URL 并点击开始。所有视图使用一个共享出口，冷 renderer JS/CSS 单独计数；每组运行 180 秒。`--python` 可选择已有科学解释器，`--real-project` 可指定已有接受记录的 MD 项目，只读原始输入，派生写入新证据目录。没有实际 WebGL/来源/帧回读的视图标为 `NOT_ACCEPTED`。

约 300 残基加小配体的工程参考目标：暖资源结构 ≤4 秒、播放 ≤6 秒、renderer 冷加载显示 ≤12 秒、缓存播放卡顿 ≤1%。10 万原子案例用于内存与文件预算检查，不能替代科学采样验收。该本地网关不等于生产 nginx、真实 SSH 路径或多设备并发验收；部署后需复核端到端吞吐和计算节点延迟。
## 本地原生体验

`node scripts/serve-bio-dsh-preview.mjs --state /absolute/new-owned-dir --port 3081 --model-home /absolute/existing-model-home` 复用原生 DSH CLI、Bio 预设、当前前端和既有模型配置。状态根必须新建且父目录已存在。演示会话最多 4 个，按钮不调用模型，科学提交/审批/advance 禁用。

工程入口自动填入一次性演示配对码，仍由用户点击“连接本地”。数据和配对均只用于明确标注的本地工程计算端；真实 SSH、HTTPS、带宽及科学验收保持待配置。该工程启动器不打入生产 Bio 源包。
